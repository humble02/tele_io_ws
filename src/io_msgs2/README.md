# io_msgs2

The ROS2 version of [io_msgs](http://git.io-intelligence.com/io_public/io_msgs).

## how to build

Make sure you have installed the [ros2](https://docs.ros.org/en/humble/index.html).

Enter your ros workspace directory and source you environment, then run the following command

```bash
colcon build --packages-select io_msgs2
```
